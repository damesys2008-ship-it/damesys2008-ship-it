## À propos

Étudiant en deuxième année d'informatique, je m'intéresse à l'ensemble de la chaîne logicielle : développement web, bases de données, scripts d'automatisation et intégration d'outils d'intelligence artificielle. Cette polyvalence est un choix : comprendre comment les applications sont construites est la meilleure base pour apprendre à les éprouver.

## Objectif

**Devenir pentester.** Je construis aujourd'hui les fondations techniques — programmation, systèmes, web — sur lesquelles repose la sécurité offensive, avant de m'y consacrer pleinement.
